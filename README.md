# prodigy_task4_DS
 **Sentiment analysis and visualization of social media data using Python, Pandas, Matplotlib, and WordCloud.**

## 📌 Task 4 – Sentiment Analysis of Social Media Data

This project focuses on analyzing and visualizing sentiment patterns in social media data to understand public opinion and attitudes toward different topics and brands.

The analysis is performed using Python, Pandas, Matplotlib, and WordCloud.

---

## 🎯 Objective

The main objective of this task is to:

- Analyze sentiment patterns in social media posts
- Clean and preprocess the dataset
- Identify the distribution of different sentiments
- Find frequently mentioned topics and brands
- Analyze sentiment across popular topics
- Identify commonly used words in social media posts
- Create meaningful visualizations from the data

---

## 📂 Dataset

The dataset contains social media posts with information such as:

- ID
- Topic/Brand
- Sentiment
- Text/Post

The dataset used for this analysis is the Twitter/Social Media Sentiment Dataset provided for the internship.

---

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- WordCloud

---

## 🧹 Data Cleaning

The following preprocessing steps are performed:

1. Loaded the dataset using Pandas.
2. Checked the dataset structure and dimensions.
3. Checked for missing values.
4. Removed rows containing missing values.
5. Converted text to lowercase for better analysis .
6. Removed punctuation from the text.
7. Removed unnecessary spaces.
8. Prepared the cleaned text for further analysis.

## 📊 Visualizations

The project includes the following visualizations:

### 1. Sentiment Distribution

A bar chart showing the number of posts belonging to each sentiment category.

- Negative: 22,358
- Positive: 20,654
- Neutral: 18,108
- Irrelevant: 12,875

### 2. Sentiment Percentage

A pie chart showing the percentage contribution of each sentiment category.

- Negative: 28.8%
- Positive: 26.6%
- Neutral: 23.4%
- Irrelevant: 16.6%


### 3. Top Topics / Brands by Mentions

A horizontal bar chart showing the most frequently mentioned topics or brands in the dataset.

### 4. Sentiment by Top Topics

A stacked bar chart comparing Negative, Positive, Neutral, and Irrelevant sentiments across the most frequently mentioned topics.

### 5. Word Cloud

A word cloud highlighting the most frequently occurring words in the social media posts.

## 🔍 Key Insights

- Negative sentiment has the highest representation in the dataset.
- Positive sentiment is the second-largest sentiment category.
- Neutral posts represent a significant portion of the dataset.
- Irrelevant posts have the lowest representation.
- Gaming-related topics and brands appear frequently in the dataset.
- Common words provide an overview of the major themes discussed in the social media posts.

The analysis provides a visual understanding of public sentiment and discussion patterns in social media data.

The generated charts make it easier to compare sentiment categories, identify popular topics, observe sentiment trends, and understand frequently discussed words.
